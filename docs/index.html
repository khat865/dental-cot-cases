ABOUT THIS COLLECTION

Images, context, and model reasoning.

This site contains all 47 cases from the diagnostic-time version of the dental CoT dataset. The original questions and model responses are preserved.

47Unique case reports
95Images in the original dataset
3Earlier English examples

The complete source dataset uses Chinese reasoning. Three cases also have an earlier English example. Each version is displayed with its own matching images; the English examples are separate rewrites, not a translation of the full 47-case dataset.

Two cases have no retained diagnostic-time images. They remain available and are marked as text-only. Source article links and license information accompany each case.

Image files are reproduced without alteration. Refer to the original articles for author credits, captions, and licensing details.
